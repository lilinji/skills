# Ringi 视觉风格指南（Visual Style Guide）

## 1. 3D 潮玩小剧场插图规范
- **画幅标准**：16:9 宽屏；
- **背景规范**：纯白无界背景（#FFFFFF），主体占比约 60%，具有微弱、柔和的环境漫反射阴影；
- **角色一致性**：Ringi（黑色短寸头、极简透明方框眼镜、绿色/黄色/蓝色圆领短袖 T 恤印字 Ringi、黑色宽松工装长裤、黑白滑板鞋、黑色方形智能手表）；
- **质感**：哑光树脂手办质感、低饱和复古色调、微缩工坊陈列感。

## 2. 暗黑极客风干架构图规范（纯矢量 SVG）
- **画幅标准**：1440x980 宽屏矢量；
- **底色规范**：深空黑底 `#0b0f19`，带细密网格线 `#1e293b`；
- **字体标准**：JetBrains Mono（代码/数值）+ PingFang SC / 苹方黑体（标题与解说）；
- **色彩规范**：
  - 青蓝 `#38bdf8` / `#22d3ee`：计算核心、用户态、通信流；
  - 翡翠绿 `#10b981` / `#34d399`：零拷贝直通、成功状态、硬件加速；
  - 琥珀黄 `#f59e0b` / `#fbbf24`：模型参数、理论指标、警示点；
  - 玫瑰红 `#ef4444` / `#fb7185`：瓶颈故障、CPU 阻塞、内存拷贝地狱；
  - 紫罗兰 `#818cf8` / `#c084fc`：存储体系、HBM、mbarrier 状态机。
