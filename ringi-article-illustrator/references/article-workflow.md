# Ringi x Baoyu 6 步深度文章分析与配图规划

## Step 1: 资产与偏好预检（Pre-Check）
- 读取 `assets/characters/ringi/character-spec-v3.md`，确认角色默认外观（极客绿 T 恤、胸前白字 `Ringi`、黑色工装裤、透明方框眼镜）；
- 读取或指定输出目录（通常为文章同级 `assets/` 目录）。

## Step 2: 深度文章阅读与认知负荷锚点提取（Deep Analysis）
1. **文章体裁识别**：
   - AI Infra / 系统工程篇：侧重分层架构、内存生命周期、吞吐与延迟；
   - 算法模型篇：侧重张量变换、注意力机制、数学推导；
   - 工具与教程篇：侧重流水线搭建、实战代码与避坑指南。
2. **定位 3~6 个认知负荷锚点**：
   - 读者读到哪里容易“头晕”或“抽象”？
   - 哪里的数据流动关系最容易产生混淆？
   - 哪里的底层物理机制与上层直觉相反？
3. **物理隐喻转化**：
   - 内存分配 -> 机械保险库 / 晶体仓库；
   - 指针移交 -> 发光钥匙 / 所有权令牌；
   - 算子分发 -> 多轨列车站 / 智能分拣器；
   - 集合通信 -> 环形传输管道 / 树状分流阀。

## Step 3: 配置与大纲规划（Outline Generation）
生成 `outline.md`，列出每张插图的：
- 对应正文小节（Position）
- 解释目的（Purpose）
- 物理隐喻与工位拆解（Visual Metaphor）
- Ringi 角色动作与配色（Ringi Action & Colorway）
- 标准文件名（Filename）
- 16:9 英文提示词（Prompt）

## Step 4: 图像生成与降级保障（Generation & Fallback）
- **有 API 时**：调用生图脚本批量生成；
- **无 API / 配额耗尽（429）时**：启动降级协议，在正文中生成 100% 结构对齐的 Mermaid 架构时序图与 ASCII 内存物理图，并附带完整 16:9 Prompt 包。

## Step 5: 正文自动组装回填（Assembly）
将插图引用以 `![Ringi 导师解构：[主题]](assets/[文件名].jpg)` 回填入正文对应锚点位置。
