# Type x Style x IP 三维矩阵说明

| 维度 | 选项 | 适用场景 |
| :--- | :--- | :--- |
| **Type (信息结构)** | `pipeline-workshop` | 多步骤流水线、计算流、通信环、编译链 |
| | `core-action` | 单一核心动作、物理移交、故障热插拔、锁操作 |
| | `memory-map` | 物理内存地址、栈堆布局、张量 Strides、Cache Line |
| | `comparison` | 双轨对比、性能对比（深拷贝 vs 零拷贝、Dense vs Sparse） |
| | `architecture` | 悬浮分层工作台、跨语言分层、模块解耦 |
| | `infographic` | 算力三账本、Roofline 模型、监控仪表盘 |
| **Style (美学质感)** | `retro-flat-3d` (默认) | 16:9 纯白底、哑光黏土手办潮玩质感、柔和接触阴影 |
| | `minimal-tech` | 极简白底极客线框科技风 |
| | `blueprint` | 严谨工程蓝图风格 |
| **IP Spec (Ringi 角色)** | `olive-green` (默认) | 经典极客绿短袖（AI Infra、底层算子、高性能计算） |
| | `mustard-yellow` | 复古暖姜黄短袖（日常创作、教程答疑、灵感发散） |
| | `slate-blue` | 科技岩板蓝短袖（分布式网络、云原生架构、集群调度） |
