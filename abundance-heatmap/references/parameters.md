# 参数口径与算法说明

配套 `SKILL.md`。改算法/默认值时，这份文档要同步改。

## 1. 相对丰度换算

```
rel[i][j] = raw[i][j] / Σ_i raw[i][j] × 100        # 除以「本样本列和」
```

- 用**列和**（每个样本自己的总量）而不是全表总量：这样每个样本内部的特征构成可比，避免样本间测序深度/总量差异带来的假象。
- **幂等性**：如果输入已经是相对丰度（列和 = 1 或 100），再除一遍列和 ×100 结果不变 → 原始计数表和相对丰度表都可以直接喂进来。
- **不适用**：输入已做过 log / z-score / 中心化 / 标准化的矩阵，除列和会二次扭曲。这类表必须 `--no-normalize`（前端会把阈值单位从 % 换成原始值，文案变成「丰度」）。
- 摘要里会打印列和范围。若列和在不同样本间差异巨大（比如 10 倍以上），说明测序深度差异大，此时列和归一化是必要的；若列和几乎相等，说明上游已经归一化过。

## 2. 两个筛选阈值（默认 AND）

| 阈值 | 默认口径 | 界面其它口径 | 什么时候换口径 |
| --- | --- | --- | --- |
| 相对丰度百分比阈值 | **平均相对丰度 ≥ 阈值**（跨全部样本的均值） | 任一（最大）样本 ≥ 阈值；至少 N 个样本 ≥ 阈值 | 「平均」压掉单样本尖峰，适合找稳定优势特征；「任一最大」保留在某个样本里爆发的特征；「至少 N 个样本 ≥ 阈值」= 丰度 + 检出率联合过滤 |
| 特征数量阈值 | **至少在 N 个样本中检出**（丰度 > 0） | 取消勾选 = 不过滤 | 去掉只在极少数样本出现的稀有特征（测序噪声、低丰度偶然命中） |

- 门槛值来自构建脚本的 `--ab-thresh` / `--prev`，界面里实时可改，改完立即重算聚类、配色、排序。
- **保留数为 0**：界面会给出「放宽阈值」的提示，不会白屏。允许的最少特征是 1 条（1 条时聚类自动关闭）。
- 交付给用户时，务必说明「当前用的是哪种口径 + 保留了多少条」（界面顶部参数条可直接截图）。

## 3. 行归一化（归一化方式 = row）

| 选项 | 公式 | 用途 / 注意 |
| --- | --- | --- |
| 行 Z-score（默认，即 row） | `(x − 行均值) / 行标准差(n−1)` | 看「该特征在自身各样本中的相对高低」。**色阶天然以 0 为中心**（蓝-白-红：蓝=低于自身均值，红=高于） |
| 行中心化 | `x − 行均值` | 只平移不缩放，行间仍保留量级差异 |
| 行 Min-Max | `(x − 行最小) / (行最大 − 行最小)` | 压到 0–1；受极值影响大 |
| log10 | `log10(x+1)` | 长尾分布、跨量级对比时用（此时阈值仍按未 log 的值算，注意口径） |
| 不归一化 | — | 直接看绝对水平 |

**可比性**：Z-score 之后行与行之间可以比较「模式」（哪里高哪里低），但**不能**比较绝对量级（每行都被压成均值 0、标准差 1）。如果要看绝对量级，选「不归一化」并把色阶的「以 0 为中心」关掉。

## 4. 聚类

- 行聚类在**归一化后的**矩阵上做（与 pheatmap / ComplexHeatmap 主流做法一致）。距离与归一化是两个独立步骤，换距离不会改变颜色。
- 距离：欧氏（默认，适合已 Z-score 的行）、相关 1−r（看形状不看重缩放）、余弦、曼哈顿。
- 连接：平均 UPGMA（默认，最稳）、完全、单链、**Ward.D2**（仅对欧氏距离有统计意义；配相关/余弦距离时结果不可解释）。
- 递推用 Lance–Williams 统一公式实现；复杂度 O(n³)，几百条特征内秒级（本技能实测 211 条 < 100 ms）。
- **树状图怎么看**：横轴长度 = 合并距离（越大越不像），纵向顺序就是热图行序；颜色与树的深浅无关，只看行内模式。
- 行序可改成：原始表顺序 / 按分类层级 / 按平均丰度降序 / 按名称——写论文附图时常用「按分类层级」分组展示。
- 列聚类默认关闭（用户要求行聚类时），可在「列顺序」里开。

## 5. 配色

- 默认「蓝-白-红」，**以 0 为中心对称**（对 Z-score 是必须的，否则 0 不在白色位置，红蓝含义会被误读）。
- 对称区间 = `±max(|v|)`，所以极端值会压扁中间色阶；觉得整体太淡时用**分位裁剪**（如 2%），把两端 2% 的极端值压到色阶两端并标注「已裁剪」。
- 顺序色板（viridis / turbo / YlGnBu / plasma / magma / 灰阶）适合「不归一化」的绝对丰度；发散色板（蓝-白-红 / 蓝-黄-红 / 红-白-蓝）适合 Z-score / 中心化。
- 分类色条：KEGG 表用 6 个一级类固定配色；无映射时每个不同取值分配色板颜色；没有注释列时该色条自动隐藏（控件置灰）。

## 6. 列内容：各样本 / 分组均值

- 「分组均值」= 每个分组内样本的**相对丰度算术平均**（n 为该组样本数），列数变成分组数（例：63 样本 → 21 组）。
- 组内重复少（n=2~3）时，分组均值视图往往比样本视图更容易看出规律；但会掩盖组内异质性，正式结论仍应回到样本视图。
- 分组均值模式下阈值筛选仍基于**样本级**相对丰度统计（不随列模式变化），保证两种视图的特征集合一致。

## 7. 导出

| 文件 | 内容 |
| --- | --- |
| SVG | 矢量图，可直接进 AI / Inkscape / PPT 编辑（已写入白底与显式宽高） |
| PNG | 2× 位图（canvas 光栅化），用于汇报 |
| TSV（归一化矩阵） | 当前视图的归一化值；行序、列序、列模式与屏幕一致 |
| TSV（相对丰度 %） | 当前视图下的相对丰度百分比矩阵 |

TSV 头部 4 行 `#` 注释记录了：数值口径（相对丰度 / 归一化方式 / 是否 no-normalize）、当前筛选阈值、列分组构成、以及「行序列序与屏幕一致」。带 UTF-8 BOM，Excel 双击不乱码；`#` 行可被 `read.table(comment.char='#')` / `pd.read_csv(comment='#')` 直接跳过。

## 8. 常见问答

**Q：热图一片浅色，看不出差异？**
A：Z-score 是对称色阶，极端值把中间压扁了。打开「分位裁剪」取 2%，或改用 turbo / viridis 这类顺序色板看绝对模式。

**Q：某个已知重要的特征没出现在图里？**
A：被两个阈值筛掉了。先在顶部参数条确认当前口径，再到「筛选」卡片放宽阈值或改口径（或直接检索名称，把其他条件放宽）。

**Q：行顺序和我表里的顺序不一样？**
A：默认「行顺序 = 聚类顺序」。要按原表顺序就把「行顺序」改成「原始表顺序」。

**Q：上传给别人看要注意什么？**
A：产物是单文件自包含 HTML（D3 已内联、无外链、无 fetch），离线双击即可，可直接邮件/IM 发送；文件名含中文也不影响。

**Q：样本名里有特殊字符 / 中文？**
A：表头按原样使用；缺失的样本名会按 `S1…Sn` 兜底，重复的特征 ID 会自动加 `#n` 后缀。
